## Что общего у всех десяти

* A4, поля 2,5 / 1,5 / 2 / 2 см, Times New Roman 10,5 пт, интерлиньяж 1,1,
  выключка по ширине, русский язык проверки орфографии в `docDefaults`.
* Каждый раздел открывается заголовком с тонкой отчёркиванием;
  шапки таблиц повторяются при переносе, строки таблиц не разрываются
  (`w:tblHeader` + `w:cantSplit`).
* Блоки **«Примечание Марии Перепечай»** — отдельная таблица с песочной
  заливкой `FFF3E0` и утолщённой левой линией: визуально не смешиваются
  с текстом договора.
* Вариативные блоки («Вариант А / Вариант Б», статусные ветви) — серо-голубая
  заливка `EEF2F7`; всё, что относится к одной ветви, лежит в одном блоке.
* Реквизиты — единая двухколоночная таблица (работодатель / работник)
  с подчёркнутой шапкой; для ИП и иностранных работников набор строк
  меняется.
* В конце — **памятка перед подписанием** с чек-боксами (на отдельной
  странице) и **единый короткий блок без цен**: индивидуальная настройка
  договора и разработка сопутствующих ЛНА — отдельно, у Марии Перепечай
  на kadry-pro.ru.
* Нет водяных знаков, логотипов, цен, «© 2025», телефонов и устаревших дат.
* Приложения внутрь не вкладываются: вместо «неотъемлемых приложений» —
  отсылки к локальным нормативным актам работодателя.

## Инструменты сборки

```
agents/agent-01/tools/
├── docx_kit.py          — конструктор Doc: вёрстка, врезки, таблицы, футер, колонтитулы
├── common_blocks.py     — повторяющиеся разделы (МРОТ, СОУТ, права/обязанности,
│                          испытание, соцстрахование, заключительные положения, реквизиты,
│                          памятка)
├── t01.py … t10.py      — генераторы каждого шаблона
├── check_docx.py        — приёмка: запрещённые формулировки, водяные знаки, обязательные блоки
├── check_ooxml.py       — порядок элементов pPr / tcPr / tblPr / rPr (схема OOXML)
├── preview_html.py      — предпросмотр .docx в HTML (A4)
└── render_preview.py    — рендер предпросмотра в PDF/PNG без LibreOffice
```

Пересборка и проверка:

```bash
for t in 01 02 03 04 05 06 07 08 09 10; do
    python3 agents/agent-01/tools/t$t.py agents/agent-01/docx-01-10
done
python3 agents/agent-01/tools/check_docx.py agents/agent-01/docx-01-10/*.docx
python3 agents/agent-01/tools/check_ooxml.py agents/agent-01/docx-01-10/*.docx
```

Зависимости: `python-docx` (проверено на 1.2.0). Для предпросмотра — `pymupdf`.

## Что проверено

* `check_docx.py` — 10/10 OK: нет цен, «© 2025», водяных знаков, ст. 212 ТК РФ,
  запрещённой формулировки о СОУТ, ссылок на приложения и устаревших норм;
  в каждом файле есть блок «Примечание Марии Перепечай» и финальный блок kadry-pro.ru.
* `check_ooxml.py` — 10/10: ни одного нарушения порядка элементов, ни одного
  дубля `w:shd` в `tcPr` (заливка шапки реквизитов ставится один раз).
* Целостность пакета: zip без ошибок, все XML разбираются, нет висячих `r:id`.
* Визуальный контроль вёрстки — рендер через PyMuPDF Story (LibreOffice в среде
  недоступен): 7–13 страниц на шаблон, врезки не разрываются, шапки таблиц
  повторяются.

## Ограничения

* LibreOffice/Word в среде сборки нет — финальную «нативную» проверку открытия
  файлов в Word выполняет владелец. Структура OOXML валидируется отдельным
  скриптом `check_ooxml.py`.
* Правовые формулировки актуальны на 24.11.2026 и требуют проверки при
  изменении законодательства.
