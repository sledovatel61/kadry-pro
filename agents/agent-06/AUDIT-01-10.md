### Риск 5. Полная материальная ответственность № 03 и дистанционная компенсация № 05: «стратегические пробелы» делают шаблоны неработоспособными

## 5. Предложение: правила ЕДИНОГО оформления будущих DOCX

> Это предложение, не правка шаблонов. Цель — чтобы клиент не мог подписать договор с рекламой, неверным основанием или отсутствующим приложением.

### 5.1. Структура файла

1. **Лист 1 — Обложка (не подписывать):** название, номер шаблона, дата версии, «проверить МРОТ/нормы на дату подписания: [___]», перечень комплекта (договор + приложения + ЛНА).
2. **Лист 2 — Инструкция по заполнению (не подписывать, удалять перед печатью):** какие поля заполнить, какие варианты выбрать, что удалить. Ссылки на статьи ТК/ФЗ с датой проверки.
3. **Листы 3+ — Текст договора (подписывать):** только условия, без рекламы, цен, телефонов, чек-листов. Нумерация пунктов сквозная; приложения — после подписей.
4. **Последний лист — Чек-лист перед подписанием (не подписывать):** контрольные вопросы с чек-боксами (как сейчас, но вне договора).

### 5.2. Заголовки

- Заголовок договора: «ТРУДОВОЙ ДОГОВОР № [___] ([вид: бессрочный/срочный/сезонный/…])».
- Разделы — только по ст. 57 ТК РФ + специальные (испытание, мат. ответственность, дистанционная, иностранцы, директор). Порядок: предмет → испытание → права/обязанности → оплата → режим/отпуск → страхование → ответственность → изменение/прекращение → заключительные → реквизиты → приложения.
- Каждый раздел — с номером статьи в скобках при первом упоминании: «(ст. 70 ТК РФ)». Ссылки на КоАП/штрафы — только в инструкции, не в договоре.

### 5.3. Поля для заполнения

- Единый формат: `[___]` — короткое поле (дата, сумма, номер); `[________________________________________]` — длинное поле (наименование, адрес, ФИО). В DOCX — поля-контент-контролы (Content Controls) с подсказкой, а не просто скобки.
- Каждое поле — с подписью: «[должность по штатному расписанию]», «[оклад цифрами]», «[оклад прописью]». Сумма — всегда цифрами + прописью.
- Обязательные поля помечать `*` и перечислять в инструкции. Необязательные — с оговоркой «если применимо — заполнить, если нет — удалить пункт целиком».

### 5.4. Обозначение альтернатив

- Взаимоисключающие варианты — только чек-боксами `☐` с пометкой «(нужное отметить, остальное удалить)». Пример: «□ основной / □ по совместительству (удалить ненужное)».
- Условные блоки — с заголовком «Заполняется только если…»: «Если класс 3.x/4 — заполнить характеристики и компенсации; если 1–2 — удалить блок».
- Запрещено оставлять в DOCX два варианта одновременно (например, «срочный / бессрочный» без выбора). В инструкции — правило: «выбрать один, удалить второй, проверить нумерацию».

### 5.5. Выделенные примечания «Мария Перепечай»

- Формат: отдельный абзац с фоном (например, светло-жёлтый), заголовком «Мария Перепечай: …» и датой проверки. В DOCX — стиль «Примечание Марии», не нумеруется как пункт договора.
- В примечания выносить: МРОТ + региональный МРОТ; СОУТ; филиал; испытание по категориям; премии; штрафы (без сумм в договоре); судебную практику (только после сверки); «стратегические пробелы» (честно: «комплект не приложен»).
- В самом договоре — только условия. Правило: «если в пункте есть цена, телефон или слово „ВНИМАНИЕ“ — это не договор, а инструкция; перенести в примечание».

### 5.6. Ссылки на нормы

- Формат: «ТК РФ, ст. 57 ч. 2», «ФЗ № 115-ФЗ, п. 8 ст. 13», «Приказ Минтруда № 251н от 16.04.2025, прил. № 3». Для каждой ссылки в инструкции — URL первоисточника (`pravo.gov.ru`) + дата проверки.
- Запрещено ссылаться на устаревшие номера (ст. 212 → ст. 214). При изменении ТК — обновлять все шаблоны партии одновременно (МРОТ, ст. 59, ст. 70).
- Судебную практику в договор не вставлять; только в примечания с реквизитами дела и датой проверки. Непроверенные ссылки — помечать «не подтверждено».

### 5.7. Элементы, удаляемые перед использованием

- Удалять перед печатью/подписанием: обложку, инструкцию, примечания Марии, чек-лист, рекламные блоки, цены, телефоны, «МП Кадры-Про» (кроме реквизитов сторон), водяные знаки, «© 2025» (заменить на текущий год), неиспользованные варианты `☐`, условные блоки «если нет оснований», пустые приложения.
- Оставлять: текст договора с заполненными полями, подписанные приложения, реквизиты, подписи, отметку о получении экземпляра.
- В DOCX — кнопка/инструкция «Удалить неиспользуемое» с перечнем. В PDF для клиента — только чистый договор (без инструкции).
