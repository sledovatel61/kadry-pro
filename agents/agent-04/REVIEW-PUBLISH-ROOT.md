**Что перестанет работать.** После публикации вернут 404 ровно 45 прямых

**⚠️ Файлы остаются в открытой истории git.** Репозиторий публичный
(`isPrivate: false`), все 64 PDF + zip сохранены в деревьях `ac75af6` и
`ba0e432` — они скачиваются любым желающим по
`https://raw.githubusercontent.com/sledovatel61/kadry-pro/ac75af6/shablony/…`
и тарболом `codeload.github.com`. Удаление из HEAD закрывает только прямые
ссылки с сайта, но НЕ скрывает контент. Полная защита потребовала бы
переписывания истории (разрушительно для всех участников) — не рекомендуется;
правильный путь — приватный R2 + подписанная выдача (см. ниже).

**Механизм выдачи вместо прямых ссылок.** `relay/src/files.ts`: подписанные
ссылки `GET /files/:token` (HMAC-SHA256 от `id|exp`, секрет `FILE_TOKEN_SECRET`)
из приватного R2-бакета `kadry-templates`; ссылка выдаётся в ответе `/leads`
на покупку шаблона. **Сейчас механизм не активен**: бакет `TEMPLATES` в
`relay/wrangler.toml` закомментирован, `FILE_TOKEN_SECRET` не задан
(`/health: files:false`). До включения платные пакеты выдаются только вручную.

**20 бесплатных PDF и старые адреса сохранены** — подтверждено пересечением
деревьев `ac75af6` и `da1ee82` (ровно 20 прежних путей живы) и `check:root`.
