# Кадры‑Про — поручения на первый цикл

## Общие правила для всех

Проект `sledovatel61/kadry-pro`, боевой сайт `https://kadry-pro.ru/`. Текущую базу `origin/main` проверь перед началом; последний подтверждённый ориентир — `cac0f7ef0c841d4f3f3d2022e260c8f67e67a7b3`, это не подтверждение боевых деплоев. Используй отдельную рабочую ветку, привязанную к твоей сессии Arena. Рабочие ссылки, SHA и проверяемые источники приложи к отчёту. На этом круге сдаём только отчёты, без изменений сайта, цен, Drive, DNS и деплоев; не мержить. Не публиковать секреты, закрытые ссылки на DOCX, данные клиентов и скриншоты с ними. Недоступную проверку пометь «не проверено» и напиши, что нужно для её выполнения. Сдача: commit и push отчёта в свою ветку, затем полный SHA, путь к файлу, 3 главных вывода и блокеры. Если ветка не видна или пуш недоступен, не утверждай, что результат на GitHub: сообщи фактический статус.

## А4 — независимая проверка опубликованных DOCX №53–64

Задача: установить, какие версии реально доступны, особенно после исторического расхождения между Git и Drive. Используй принятый комплект Писаря `ca9649c240f92bf88cef8a6d0c83c676f491ca2a`, повторное ревью А4 и [PR №18](https://github.com/sledovatel61/kadry-pro/pull/18). Сверь для 12 позиций карточку, бесплатный/платный статус, название, превью и фактически выдаваемый DOCX. Где есть разрешённый доступ к файлу — сравни хеш с эталоном. Если доступа нет, дай Марии короткий список проверок; не выдавай совпадение имени за совпадение версий. Отдельно проверь №53 и №64 в Word или доступном рендерере, указав его. На этот круг прежние партии не перепроверяем полностью. Сдать таблицу «№ / карточка / превью / файл совпадает, не совпадает или не проверен / что делать» в `agents/agent-04/PROD-DOCX-53-64.md`.
